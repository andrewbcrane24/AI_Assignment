# Credit Card Fraud: Exploratory Data Analysis

## What this notebook analyzes
- For this project, we are trying to figure out how to find fraudulent transactions vs real ones.
- The dataset has 999 transactions and 8 columns that give more context.
- This file figures out how to clean the dataset, how to show graphs that may give a better understanding to what can differentiate authentic vs fraudulent transactions.

## Files in this repo
- `fraud_eda.ipynb`: the analysis, pre-run with all outputs
- `card_transdata.csv`: the dataset
- `README.md`: this file

## How I used AI
- **AI system(s) and version(s): I used Claude Sonnet 5.5.
- I put the files into AI to give it context for what to work with and then I had AI give me a new notebook that replicated (without the full context of the actual notebook) what we worked with to make it solve the problems that we were working on.
- I gave AI a better understanding of what needs to be done and explained the context behind what the AI needs to do.

## Reflection on AI assistance

**Paragraph 1: benefits and dangers**
Using AI to recreate a notebook like this is very useful. It is efficient and less error prone than a human may be and that is why it becomes easier to use. It can definitely become a crutch which is dangerous because it takes away human thought and problem solving, which is how we continue to learn.

**Paragraph 2: verification**
I was able to check the notebook to see the similarities and differences with the original notebook. It was interesting to see how AI understands these projects vs how a teacher may see it. The human aspect is different in its intuitiveness. All in all, AI is very interesting to see and to use when it comes to replicating work. It is also amazing to see how quickly it can do the same work that we spend a lot of time working on.
